❯ 请问 K=1 参考基线中的这个K指的是什么？                                        

● K 指的是模型预测的轨迹候选数量（number of predicted modes）。

  ---
  背景

  运动预测是一个多模态问题——同一辆车在路口可能左转、直行、右转，未来有多种合理可
  能。因此标准评测协议允许模型一次预测 K
  条轨迹，然后取最接近GT的那条来计算指标：

  $$\text{minADE}K = \min{k=1}^{K} \text{ADE}(\hat{\tau}k, \tau{GT})$$

  ---
  K 越大，指标越好

  ┌──────┬───────────────────────────┬────────────────────────┐
  │  K   │           含义            │        指标难度        │
  ├──────┼───────────────────────────┼────────────────────────┤
  │ K=1  │ 只预测1条轨迹，必须"押对" │ 最难，指标最高（最差） │
  ├──────┼───────────────────────────┼────────────────────────┤
  │ K=6  │ 预测6条轨迹，取最近的     │ AV2官方标准            │
  ├──────┼───────────────────────────┼────────────────────────┤
  │ K=64 │ 预测64条，覆盖更多可能性  │ 最容易刷低指标         │
  └──────┴───────────────────────────┴────────────────────────┘

  ---
  你的情况

  你的模型当前只输出1条轨迹（MLP直接回归），所以对比的是 K=1 
  baseline（1.837m），这是同等条件下最公平的对比。

  AV2排行榜上的顶级方法（如 MTR、HiVT）通常在 K=6 下评测，ADE 可到
  0.6-0.8m，但那是"6选1"，不能直接与你的结果比较。

  ---
  简言之：K=1 意味着单次预测，不允许多猜，是最严格的评测标准。

● 很好，代码清晰地展示了三种方法的实现。下面详细介绍。

  ---
  SIMPL 中的三种轨迹参数化方法

  代码在 simpl/simpl.py:430 通过 param_out
  控制输出模式，AV2配置（simpl_av2_cfg.py:37）使用 bezier + 7阶。

  ---
  方法一：直接回归（param_out='none'）

  MLP 直接输出 60×2 = 120个数值，每个时间步单独预测。

  hidden → MLP → [60, 2]  (60步的 x,y 坐标)

  - 优点：最简单，无先验约束，最灵活
  - 缺点：参数量最多；相邻时间步之间没有平滑约束；容易产生抖动轨迹

  你的LLM模型目前就是这种方式。

  ---
  方法二：Bernstein基（Bézier曲线，param_out='bezier'）

  不直接预测60个点，而是预测 N+1 个控制点，再通过固定的 Bernstein 基矩阵 T
  展开成60个点：

  $$\mathbf{P}(t) = \sum_{i=0}^{N} \binom{N}{i}(1-t)^{N-i}t^{i} \cdot
  \mathbf{c}_i$$

  代码实现（simpl.py:493-499）：
  # 预计算 T 矩阵 [60, N+1]，固定不变
  ts = np.linspace(0.0, 1.0, 60)
  T[i] = C(N,i) * (1-t)^(N-i) * t^i

  # 前向传播：
  param = MLP(hidden)  → [N_ORDER+1, 2]  # 只需预测 8 个控制点（7阶）
  traj  = T @ param    → [60, 2]         # 矩阵乘法展开

  SIMPL AV2 用 7阶 → 8个控制点，相比直接回归的120个值，压缩了15×。

  - 优点：天然平滑（C^∞连续）；参数极少；导数也有解析表达（mat_Tp用于计算速度）
  - 缺点：强光滑先验，局部突变（如急刹）可能拟合不好；控制点无直观物理意义

  ---
  方法三：单项式基（标准多项式，param_out='monomial'）

  用普通幂基 $1, t, t^2, \ldots, t^N$ 展开：

  $$\mathbf{P}(t) = \sum_{i=0}^{N} \mathbf{a}_i \cdot t^i$$

  代码（simpl.py:511-517）：
  T[i] = t^i   # 简单幂次

  - 优点：与 Bézier 同等参数量；系数 $\mathbf{a}_i$
  有直观含义（$\mathbf{a}_0$=初始位置，$\mathbf{a}_1$=初速度）
  - 缺点：数值不稳定——高阶时 $t^7$ 在 t=1 时梯度极大，训练容易爆炸；实践中
  Bézier 通常优于 monomial

  ---
  三种方法对比

  ┌────────┬─────────────┬───────┬──────────────────┬─────────────────────┐
  │  方法  │ 输出维度（A │ 平滑  │    训练稳定性    │    SIMPL AV2默认    │
  │        │  V2, N=7）  │  性   │                  │                     │
  ├────────┼─────────────┼───────┼──────────────────┼─────────────────────┤
  │ none   │ 120         │ 无保  │ 稳定             │ 否（SIMPL-argoverse │
  │        │             │ 证    │                  │ 用）                │
  ├────────┼─────────────┼───────┼──────────────────┼─────────────────────┤
  │ bezier │ 16          │ 极佳  │ 稳定             │ 是                  │
  ├────────┼─────────────┼───────┼──────────────────┼─────────────────────┤
  │ monomi │ 16          │ 极佳  │ 较差（高阶数值问 │ 否                  │
  │ al     │             │       │ 题）             │                     │
  └────────┴─────────────┴───────┴──────────────────┴─────────────────────┘

  ---
  对你的LLM模型是否可行？

  结论：可行，且值得尝试，但收益边际。

  ┌──────────┬───────────────────────────────────────────────────────────┐
  │   考量   │                           分析                            │
  ├──────────┼───────────────────────────────────────────────────────────┤
  │ 参数减少 │ 120→16，MLP最后一层更容易优化                             │
  ├──────────┼───────────────────────────────────────────────────────────┤
  │ 平滑约束 │ 对文本编码器输出的低精度特征有"正则化"效果                │
  ├──────────┼───────────────────────────────────────────────────────────┤
  │ 零初始化 │ 控制点全零 → 轨迹全在原点，和直接回归一样有初始化偏差问题 │
  ├──────────┼───────────────────────────────────────────────────────────┤
  │ 主要瓶颈 │ 当前差距主要来自LLM特征缺乏空间精度，不是回归头的表达能力 │
  └──────────┴───────────────────────────────────────────────────────────┘

  优先级建议：先做位移预测（解决坐标范围问题），再考虑换成 Bézier
  头——两者可以叠加，但位移+Bézier的组合需要在损失计算时注意坐标系的一致性（累积
  求和还是对控制点做cumsum）。
