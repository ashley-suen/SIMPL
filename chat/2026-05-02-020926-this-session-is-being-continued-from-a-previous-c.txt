  ---
  根本原因分析

  1. Loss 与评估指标脱节（核心问题）

  Exp2 训练 loss 优化的是每步位移误差（约 ±0.001m 量级），但 ADE/FDE 是累积 60 
  步后的绝对位置误差。loss 下降 0.001 不代表 ADE 改善
  0.001m，二者的梯度方向不完全一致。

  2. 每 epoch improve 极低的本质

  Exp1 val loss 从 ~6.5 降到 ~5.1，每 epoch 可见 0.05-0.1 的改善。
  Exp2 val loss 从 0.074 降到 0.065，整个 14 个 epoch 只降了 0.009，每 epoch
  不足 0.001——这意味着每次 checkpoint
  保存的阈值很低，验证体系在测量"位移层面的精度"，而 ADE/FDE 是 position
  层面的，两者脱钩。

  3. 这正是为什么我们实现了 hybrid loss 但尚未用

  当前 Exp2 是 pos_loss_weight=0（纯位移 loss）。av2_llm_loss.py 里已经实现的
  pos_loss 直接对 cumsum 后的绝对坐标计算 SmoothL1，这才是与 ADE/FDE
  对齐的信号。

  ---
  建议

  不要等 ep20，现在停掉 Exp2，直接启动 Exp3（hybrid loss）。

  理由：ep15-19 的 LR 近乎为零（4e-06 →
  0），就算跑完也只是在当前局部最小值附近震荡。更关键的是，warm restart 解决不了
   loss-metric 脱节问题——LR 重置后，梯度信号仍然错误。

  对齐，同时保留 disp_loss 维持每步约束。

❯ 有没有什么针对模型的改进？而不是仅仅的调参                                    

● 好问题。调参是在现有架构的上限内打磨，真正的提升需要改变模型的信息输入或预测机
  制。以下是几个有实质性意义的模型级改进。

  ---
  1. 加入地图信息（最高优先级）

  当前问题：模型完全看不到道路结构。预测车辆轨迹却不知道车道在哪，相当于蒙眼开车
  。

  AV2 数据集提供完整 HD 地图（车道中心线、边界线、人行横道等），SIMPL 的原始
  pipeline 已经处理了这些数据，但 LLM head 完全没有利用。

  实现方案：在 prompt 中加入 focal agent 附近的车道中心线，例如：

  [Nearby lanes]
  Lane 0: (1.2, 0.5) → (3.1, 1.8) → (5.0, 3.2) → ...
  Lane 1: (-0.5, 0.3) → (-0.3, 2.1) → ...

  预期收益：地图感知是轨迹预测最关键的上下文信息。AV2 排行榜上有地图 vs
  无地图模型的 ADE 差距通常在 0.5-1.5m，这是单次改动中收益最大的。

  ---
  2. Agent 间交互模块（Social Attention）

  当前问题：Agent 之间的交互仅靠 LLM 在文本层面隐式捕捉（多个 agent 的 token
  拼接在同一段文本里），没有显式的 agent-agent 交互建模。

  实现方案：在 LLM 提取完每个 agent 的 token 表示后，加一个轻量 Cross-Attention 
  层，让每个 agent 的表示能够显式 attend 到其他 agent：

  LLM hidden states: [B, N_agents, D]
         ↓
  Cross-Attention(Q=agent_i, K=V=all_agents)  ← 新增
         ↓
  MLP head → trajectory

  这一改动不动 LLM backbone，只在 MLP head
  前插入一个小模块（参数量很小），但直接建模了"我的运动受别人影响"的物理直觉。

  ---
  3. 多模态预测 K=6（范式改变）

  当前问题：K=1 即单一轨迹预测，是最难的设定。AV2 官方排行榜用的是 K=6——模型输出
   6 条候选轨迹，取与 GT 最近的那条计算 ADE/FDE。

  当前 K=1 的 ADE 约 4.67m，而 AV2 leaderboard 上 K=6 的 SOTA 约 
  0.6-1.2m，差距巨大的根本原因是 K。

  实现方案：将 MLP head 的输出维度从 [60, 2] 扩展为 [K, 60, 2]，训练时用
  Winner-Takes-All（WTA）loss——只对 K 条预测中最接近 GT 的那条反向传播梯度：

  # K=6 candidates: [B, N_agents, K, 60, 2]
  # 计算每条候选轨迹的 ADE，选最小的那个
  ade_per_k = (pred_abs - gt_abs).norm(dim=-1).mean(dim=-1)  # [B, N, K]
  best_k = ade_per_k.argmin(dim=-1)  # [B, N]
  # 只对 best_k 对应的候选计算 loss

  这是方法层面最根本的改变，也是与 AV2 官方评估对齐的必要条件。

  ---
  4. 轨迹离散化 Token 预测（最符合 LLM 本质）

  当前问题：用 LLM 回归连续的 (dx, dy) 数值，但 LLM 预训练的目标是下一个 token 
  的分类。两者存在根本性的任务错位。

  实现方案：将位移空间量化为离散 bin，变成分类任务：

  dx ∈ [-2m, 2m] → 分成 200 个 bin（精度 0.02m）
  dy ∈ [-2m, 2m] → 同上

  每个时间步预测 (dx_token, dy_token) 两个 token，整条轨迹变成长度 120 的 token
  序列，用交叉熵 loss 训练，完全对齐 LLM 的预训练机制。这也是 MotionGPT、TrajLLM
   等工作的核心思路。
