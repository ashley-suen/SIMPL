● The code looks solid. Here's a quick review of the changes:

  What's well done:

  1. save_last_every_epoch (lines 267-269) — correctly fixes the single-epoch
  save bug. Previously a checkpoint was only written when val loss improved; now
   a _last.tar is always written at epoch end, independent of validation.
  2. Fail-fast checks (lines 99-116) — write probe + val_interval > 
  train_epoches guard before training starts. Good practice, avoids wasting GPU
  time.
  3. safe_save wrapper (lines 72-85) — wraps save_ckpt with exception handling
  and verifies the file actually landed on disk with its size. Much safer than a
   silent failure.
  4. Running-window loss via deque(maxlen=...) (lines 190, 228) — correct
  implementation. The window size is configurable via --running_window.
  5. Periodic stdout print (lines 233-254) — essential when redirecting to nohup
   log; tqdm bars don't flush properly to files.

  One minor edge case to be aware of:

  In the FDE calculation at line 302:
  last_valid_idx = (mask_focal.long().cumsum(dim=1) *
  mask_focal.long()).argmax(dim=1)
  If a sample has all-zero mask (no valid timesteps), argmax returns 0, and FDE
  falls back to disp[:, 0] — not meaningful. This is unlikely in practice since
  focal agents almost always have valid futures, but worth noting if you ever
  see suspiciously low FDE values.

  One dead variable: saved_any is tracked on lines 171/269/334 but never used in
   the final warning — the final check uses glob directly instead, which is
  actually more reliable. The variable can stay as-is; it's harmless.

  Overall the changes are clean and correct. The single-epoch save fix and the
  rich logging are both solid improvements.

  运动预测真正困难的部分是什么？

  传统方法（SIMPL, MTR, HiVT等）在几何精度上已经很强，但有两个根本弱点：

  弱点1：无法理解社会规范和意图

  ▎ 红灯前的车会刹车、救护车会变道、行人会等待后再过马路

  弱点2：罕见场景泛化能力差

  训练数据中没见过的场景（施工绕行、突发事故）几何模型直接失效，但LLM见过大量关
